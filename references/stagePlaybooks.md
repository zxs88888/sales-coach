# Stage Playbooks — 销售阶段剧本

销售六阶段：**线索培育 → 商机 → 方案 → POC → 谈判 → 落地**。
阶段切换时，作战卡模块⑥整体按新阶段剧本重算，并在策略快照记录阶段变更。
下列「必聊3问/带材/离开前确认/下一步」为种子话术，需结合立场矩阵(companyMatrix.json)与我方产品动态填充，
**禁止留空——任一阶段内容空洞即视为未完成**。

## 1. 线索培育（Lead Nurturing）★写满
- **阶段目标**：建立认知、确认客户有潜在需求与预算窗口，进入商机评估。
- **建议对接人**：业务侧联系人 / 初步技术接口人。
- **必聊 3 问**：① 当前这块业务/系统是怎么解决的？痛点多大？② 今年有没有相关的预算或规划？③ 谁在内部推动这件事？
- **可带材料**：我方 1 页价值主张、同行业标杆案例（匹配 companyMatrix 的 caseIndustries）。
- **离开前必须确认的一件事**：客户是否愿意进入一次正式需求沟通（商机确认）。
- **下一步日历提醒**：7 天内发送定制行业洞察 + 约需求沟通会。

## 2. 商机（Opportunity）— 骨架
- **阶段目标**：明确需求范围、预算、决策链，输出机会评分。
- **建议对接人**：业务负责人 + 技术评估人。
- **必聊 3 问**：① 需求优先级与成功标准？② 预算区间与审批路径？③ 时间窗与竞品是否在场？
- **可带材料**：需求调研提纲、ROI 粗算。
- **离开前必须确认**：是否进入方案/报价阶段。
- **下一步**：10 天内提交初步方案。

## 3. 方案（Proposal）— 骨架
- **阶段目标**：给出匹配客户场景的方案 + 初步报价，锁定技术认同。
- **建议对接人**：技术负责人 + 采购。
- **必聊 3 问**：① 方案是否满足技术与合规要求？② 报价结构是否可接受？③ 还需哪些决策人认可？
- **可带材料**：正式方案书、报价单、安全合规材料。
- **离开前必须确认**：技术方案无异议，进入 POC 或商务谈判。
- **下一步**：约定 POC 范围与成功标准。

## 4. POC（概念验证）★写满
- **阶段目标**：用真实场景小规模验证我方价值，消除技术/效果疑虑，拿到"继续推进"承诺。
- **建议对接人**：技术负责人（CTO/架构师）+ 业务试点 owner。
- **必聊 3 问**：① 试点的成功标准由谁定义、怎么量化？② 试点如何轻量启动（如用悟空自动化工单、MuleRun 跑营销），需要客户提供什么？③ 试点结束后的决策路径与席位扩容意向？
- **可带材料**：POC 方案（场景/数据/时长/验收指标）、我方技术支撑承诺、试点排期。
- **离开前必须确认的一件事**：双方书面确认试点成功标准与"效果达标后进入席位采购"的承诺。
- **下一步日历提醒**：POC 启动会 + 每周同步，结束前 3 天预约复盘会。
- **打法提示**：借立场矩阵 defaultPositioning（如千问办公以"钉钉入口+企业Agent整合"为差异化），把试点场景选在客户协同/自动化最痛处（工单、营销、跨系统数据搬运）。

## 5. 谈判（Negotiation）★写满
- **阶段目标**：敲定商务条款、封堵竞品、锁定签约，处理异议与价格。
- **建议对接人**：采购 + 决策层 + 我方销售负责人。
- **必聊 3 问**：① 最终决策人与签字时间？② 价格/条款最大的卡点是什么？③ 竞品给了什么条件、我们怎么应对？
- **可带材料**：标准价目+席位包（如 MuleRun ¥420/席/月）、差异化对比（基于 competitors.knownWeaknesses，正面表述我方优势）、轻量服务条款说明。
- **离开前必须确认的一件事**：客户口头/书面确认签约意向与大致时间。
- **下一步日历提醒**：24h 内发出合同 + 约签约；同步准备异议应对（见作战卡模块⑥异议库）。
- **打法提示**：用矩阵中竞对 knownWeaknesses 做正面差异化（如打飞书/企微的"Agent 整合弱、无独立编程 Agent"），**禁止贬低友商**(遵守 avoidPhrases)。

## 6. 落地（Deployment）— 骨架
- **阶段目标**：顺利交付、拿到增购/转介绍，沉淀案例。
- **建议对接人**：客户成功/实施 + 业务 owner。
- **必聊 3 问**：① 上线后成功指标达成情况？② 有无增购/跨部门推广场景？③ 是否可做案例/转介绍？
- **可带材料**：交付计划、成功度量表、增购方案。
- **离开前必须确认**：客户愿意进入席位扩张/增购或案例共创。
- **下一步**：交付启动 + 30 天回访。
